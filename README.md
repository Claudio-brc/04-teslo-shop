# Teslo API

1. clonar proyecto
2. ```npm install````
3. clonar el archivo ```.env.template``` y renombrarlo ```.env````
4. cambiar variables de entorno
5. Levantar DB

```
docker-compose up -d
``` 

6. Ejecutar SEED
```
localhost:3001/api/seed
``` 

7. levantar: ```npm run: dev```
